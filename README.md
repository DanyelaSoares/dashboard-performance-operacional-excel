# 📈 Dashboard de Performance Operacional — Excel

Projeto desenvolvido para estudo e demonstração prática de conhecimentos em **Microsoft Excel**, simulando o acompanhamento de demandas e indicadores operacionais de uma empresa.

A proposta é transformar uma base de dados operacional em informações úteis para acompanhamento de produtividade, cumprimento de prazos e qualidade do atendimento.

## 🎯 Objetivo

Desenvolver um dashboard capaz de apresentar indicadores de performance e permitir uma visão gerencial dos processos.

O projeto busca praticar:

- Organização e análise de dados
- Criação de indicadores (KPIs)
- Análise de produtividade
- Controle de prazos
- Análise de SLA
- Análise de satisfação
- Construção de gráficos
- Fórmulas e funções do Excel
- Tabelas Dinâmicas
- Power Query

## 📁 Estrutura do projeto

### 📊 Dashboard

Painel de acompanhamento da performance operacional.

Principais indicadores:

- Demandas recebidas
- Demandas concluídas
- Percentual de SLA cumprido
- Índice de satisfação
- Demandas por área
- SLA por responsável
- Evolução mensal de demandas

### 🗂️ Base_Operacional

Base fictícia com 500 registros de demandas operacionais.

Os registros possuem informações como:

- ID
- Data
- Responsável
- Área
- Canal
- Tipo de demanda
- Status
- Prioridade
- Data de abertura
- Data de conclusão
- Prazo
- Tempo de atendimento
- SLA
- Satisfação do cliente

### 📚 Apoio

Dicionário dos campos utilizados na base, facilitando a compreensão dos dados e da estrutura do projeto.
